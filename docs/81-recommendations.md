# Recomendaciones

- **Sobre la continuidad del producto:** Como siguiente etapa posterior a la entrega final, se recomienda priorizar un piloto controlado en un establecimiento real o simulado con usuarios representativos. Esto permitirá medir tiempos de operación, errores de uso, carga percibida y valor práctico de los flujos clínicos y administrativos ya implementados.

- **Validación con usuarios y métricas de uso:** Se recomienda ejecutar pruebas formales de usabilidad con médicos, personal administrativo y pacientes, incorporando métricas como tiempo por tarea, tasa de éxito, puntos de fricción y satisfacción general. Esta evidencia permitirá convertir la validación cualitativa del proyecto en insumos concretos para una futura iteración del producto.

- **Seguridad, auditoría y cumplimiento:** Aunque ya se incorporaron JWT, sesiones seguras y protección de información sensible, se recomienda profundizar en auditoría de acciones, políticas de respaldo, gestión de permisos más granular y alineamiento con requisitos normativos aplicables a datos de salud. Esto es clave si Vitalia evoluciona hacia un entorno productivo real.

- **Madurez de integraciones externas:** Se recomienda consolidar las integraciones con servicios de identidad y pagos, y extenderlas hacia servicios complementarios como facturación electrónica, notificaciones transaccionales y exportación de documentos clínicos. Una estrategia de integración bien definida aumentará el valor operativo del sistema en escenarios reales.

- **Calidad técnica y escalabilidad:** Se sugiere fortalecer la cobertura de pruebas automatizadas, observabilidad, manejo de errores y monitoreo de despliegues para sostener el crecimiento del sistema. Del mismo modo, conviene seguir refinando contratos API, catálogos clínicos e inventarios para facilitar mantenimiento, escalabilidad y futuras integraciones.

- **Mantenimiento documental y de proceso:** Se recomienda conservar el enfoque de Docs-as-Code y la disciplina de trazabilidad entre backlog, commits, evidencias y entregables. Esta práctica no solo mejora la comunicación del equipo, sino que también deja una base ordenada para transferencia de conocimiento, auditoría académica o continuidad del proyecto.
